### F2 关于 `cache:'no-store'`（如实，不假装看到头）

请求头逐字：`accept` / `referer` / `user-agent` / `sec-ch-ua*`；**没有** `Cache-Control` / `Pragma` /
`If-None-Match` / `If-Modified-Since`（F-raw.log:229-249）。`cache:'no-store'` 是 Fetch API 的
`RequestCache` 指令（`fzstdLoader.ts:98` 的 `fetch(url,{cache:init.cache})`），由浏览器在 HTTP 缓存层执行
「不读/不写缓存」，**不必然产生请求头**；「没看到头」既不支持也不否定 no-store 生效。本票对 no-store 的
**可证伪证据**是：URL 带每页唯一 nonce（F4）+ 同一 document 只发 1 次（F3）+ 反向断言里失败后本 document
永久不可用不重试（F8-5）。

## 未验边界（如实）

1. **CDN 边缘节流**：连续多次重复拉 ~38 MB 时，同一出口偶发「⏳ Downloading」长时间不收敛
   （本轮一次独立诊断：卡在 2 个分片 / 120 s；票 C 2026-11-06 裁定亦记录同款现象）。实测小对象
   会被限速到 4–8 KB/s，大分片仍 1.5 MB/s。这不是产品缺陷：
   - fzstd 是**懒加载**（zstd 解码要开始时才有），下载卡在开始前 ⇒ 该 document fzstd 0 次；
   - 独立探针 `noncediag-1106f.mjs` 连开 3 个全新 document，3/3 在 2–6 s 内拿到 32-hex nonce；
   - 复钓脚本因此带**自身判据**：卡住的 document 关掉重开（最多 4 次），逐字记录每次的
     等待时长/分片数/失败原因，只把成功触发 fzstd 的 document 计入 nonce 集合。
   - 权威全量跑 2 次尝试 2 次成功（F-raw.log:616），**未把节流窗口误报成产品 FAIL**。
2. **cross-tab / 跨进程持久性未直接验**：`fzstdLoader` 的 memo 是 document 级单例，本票在同一浏览器进程内
   用「全新 context = 全新 document」证每页唯一 nonce；未验证浏览器重启后 HTTP 磁盘缓存是否残留该资源。
   但 `cache:'no-store'` + 每页唯一 nonce 使缓存键结构上不可复用，且 F5 确认无 CacheStorage 条目、
   无 4 类传统 storage 条目。
3. **`cache:'no-store'` 头语义未验**（见 F2）：只如实说明「请求头里没有 cache-ish 头」，用 nonce 唯一性 +
   单 document 单次 + 反向断言间接证伪，未假装看到 `Cache-Control` 头。
4. **OPFS 只验「无 fzstd 模块字节」**：OPFS 里引擎资产目录是产品正常落盘（见 F5）；本票未逐字节扫描
   >2 MiB 的大文件内容（这些是引擎 wasm/data，不是 fzstd 模块）。fzstd 模块为 24407 B 文本，特征串扫描覆盖它。
5. **GH 备线（`base_proxy`）未走**：本轮 catalogue 的 `base` 全命中 EO 主线 `static.isui.ren`，
   23 条外部请求零失败；未复现 11-05 记录的 GH 直连间歇超时，也未验 CF 镜像
   `static.mango-mesa.ccwu.cc` 的回退路径（主线可用时按序探测不会走它）。
6. **并发峰值是 Playwright 网络层记账**（`request` → `requestfinished` 同时在飞的分片数），非内核 socket 计数；
   与 `chunkAssembler.ts:104` 的 `DEFAULT_CONCURRENCY=2` 及分片时序（两个 worker 排队取号）互证。
7. **工作树并发改动（非本代理所改）**：本会话期间仓里有别的 agent 的未提交改动
   （`src/modules/appContext.ts` 12:12、`src/modules/storage/DownloadStore.ts` 12:39、
   `tests/storage/DownloadStore.test.ts` 12:38、`dist/index.html` 12:18 等）。
   这些**不影响本票证据**：8904 服务的是 `/tmp/fishing-2026-11-05/dist-clean`（11:12:26 后
   0 文件被改动），且已复核该净化盘的构建产物 `_astro/App.pqSaCRSx.js` 仍含
   `1a901fc5a58c349bb`（钉值）、`lib/fzstd-0.1.1.mjs`、`?v=`、`zstd decoding disabled`、
